## 4. 優先順位（仮説・見直し可）

1. B: 15秒デモ動画 → 到達 → 地図利用
2. A: 既存ガイドの改稿
3. C: 自分用の路線図を保存・共有して再訪（最小版）
4. E: 観光の文脈に合う成果報酬型提携
5. D: イベント会場・宿泊施設向けアクセス地図提供

優先度を下げる: 家賃・治安記事の量産／一般向け月額課金（依頼者指定）／検索流入ページの量産（既存資産と重複するため独自判断で追加）。

## 5. 4週間実験（B案）の判定基準

初回計測の基準が無いため数値はすべて暫定。到達 → 地図利用 → 再訪 → 収益 の順に重視。順位・再生数は補助指標。

| 判定 | 条件 | 行動 |
|---|---|---|
| 継続 | UTM経由の到達あり かつ 最良フックが他案の2倍以上 かつ 再訪を確認 | 勝ちフックで本数増、Cに着手 |
| 修正 | 到達はあるが地図CTA到達率が3案とも同水準で低い | 遷移先ページ（FV・CTA文言）を差し替えて再実験 |
| 中止 | 2週目終了時にUTM経由の到達がほぼ0、または測定不能 | Bを止め、Aを主軸に切り替え |

前提: GA4測定IDが未設定の場合、Bは開始せず「計測の有効化 → A → B」に順序を組み替える。
